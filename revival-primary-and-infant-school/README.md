# Revival Primary and Infant School: website concept

A one-page demo website for Revival Primary and Infant School and its new
Infant Department. It is a concept to show the Principal. Contact details,
dates and figures are samples.

Open `index.html` in any browser to view it. No install or server needed.

## Files

- `index.html`: the whole site
- `logo.webp`: the school badge with the two laurel branches removed, sized
  for the website
- `logo.png`: the same badge at 1024 px with a transparent background, for
  print or other uses
- `principal.webp`: the Principal's photo for the welcome section. It is not
  stored in this public repository; add it to this folder to see it on the page.

## What's on the page

- **School badge** in the header, the hero and the footer
- **Hero illustration**: toy blocks spelling REVIVAL and LEARN, with a crane
  lowering the last block
- **Build tracker** for the new Infant Department: progress meter, milestones
  and a live countdown to the target opening day
- **Principal's welcome** with photo and message
- **Pathway**: Age 3, Age 4 and Age 5 infant classes leading into Grade One in
  the same school
- **What children learn**: six learning areas
- **Our day**: daily schedule with a live "right now" card on Jamaica time
- **News and events**: filterable notice board and term dates
- **Help us build**: wish list with progress bars and ways to give
- **Register interest**: form with a class finder that works out the child's
  class from their date of birth (demo only, nothing is sent)
- **FAQ, contact details, light and dark themes, mobile menu**
- **Notes for the Principal**: a button in the top banner shows sticky notes
  that explain what to put in each section

## Before going live

1. Replace the sample phone, email, address, dates and wish list figures.
2. Add the Principal's name and own welcome message, and real photos of the
   build.
3. Connect the registration form to the school's email or WhatsApp.
4. Remove the "Website concept" banner and the Principal's notes.

To put it online for free, upload this folder to GitHub Pages, Netlify or
Cloudflare Pages.
