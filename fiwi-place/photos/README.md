# FiWi Place photos

Upload the photos from the "fiwi place" Desktop folder here, keeping their
original file names (titles). Claude uses the titles to place them:

- Titles naming an event or section (e.g. "baby shower", "birthday",
  "wedding brunch", "private dinner", "venue", "gallery") go into that section.
- Titles containing "view" are combined into the Yard View slideshow video.
- Titles containing "extra photo" go into the Extra Photos section.
